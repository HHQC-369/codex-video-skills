# 印刷工艺与装订结构匹配

## 专属职责
- 只负责：**印刷工艺与装订结构匹配**。
- 跨领域项交给 Orchestrator/对应子 Skill，不在本 Skill 内复制其它岗位逻辑。
- 共用事实边界见 `../_shared/CORE_POLICY.md`。

## 触发条件
- 丝网印刷后怎么装订
- 印刷工艺对胶装有什么影响

## 必要输入
- 印刷方式
- 纸张/油墨/表面处理
- 后道装订

## 专业执行SOP
1. 识别印刷工艺
2. 列装订相关表面/折页/压痕风险
3. 检查后道兼容
4. 输出需试样项

## 专属硬停止条件
- 印刷工艺不能替代纸张/胶水实测
- 未知干燥/附着参数不得猜
