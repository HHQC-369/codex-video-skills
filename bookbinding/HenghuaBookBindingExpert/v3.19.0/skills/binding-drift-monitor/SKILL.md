# 生产表现漂移监控

## 专属职责
- 只负责：**生产表现漂移监控**。
- 跨领域项交给 Orchestrator/对应子 Skill，不在本 Skill 内复制其它岗位逻辑。
- 共用事实边界见 `../_shared/CORE_POLICY.md`。

## 触发条件
- 最近PUR返工率突然升高
- 检查某装订方式近期是否变差

## 必要输入
- 基线窗口
- 近期窗口
- 方法/设备/材料维度

## 专业执行SOP
1. 计算基线与近期表现
2. 按drift_policy判断
3. 只触发复核链
4. 列出材料/设备/参数/操作排查维度

## 专属硬停止条件
- 漂移不得自动改规则
- 小样本不得下趋势结论

## 专属资源
- `../../calibration/drift_policy.json`
- `../../scripts/drift_monitor.py`

## 输出字段
- `漂移状态`
- `差异`
- `复核清单`
