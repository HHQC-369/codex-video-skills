# 书籍保护盒/护套工程

## 专属职责
- 只负责：**书籍保护盒/护套工程**。
- 跨领域项交给 Orchestrator/对应子 Skill，不在本 Skill 内复制其它岗位逻辑。
- 共用事实边界见 `../_shared/CORE_POLICY.md`。

## 触发条件
- 做连盖收藏盒
- 给这本书设计保护护套

## 必要输入
- 成书实测尺寸
- 盒型
- 材料厚度
- 取放要求

## 专业执行SOP
1. 选择enclosure结构
2. 按来源参数生成参考尺寸关系
3. 制作白样
4. 检查取放/间隙/边角

## 专属硬停止条件
- 未实测成书不得定最终内尺寸
- 古典盒参数不得直接泛化到工业刀模
