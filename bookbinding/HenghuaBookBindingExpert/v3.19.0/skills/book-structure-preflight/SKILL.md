# 书籍结构印前检查

## 专属职责
- 只负责：**书籍结构印前检查**。
- 跨领域项交给 Orchestrator/对应子 Skill，不在本 Skill 内复制其它岗位逻辑。
- 共用事实边界见 `../_shared/CORE_POLICY.md`。

## 触发条件
- 精装封面文件怎么检查
- 跨页图片会不会吃进中缝

## 必要输入
- 成品尺寸
- 页数
- 书脊/封面结构
- 跨页/安全区

1. 识别结构部件
2. 检查书脊/槽/飘口/环衬字段
3. 检查跨页与中缝风险
4. 输出缺失参数

- 设计安全区与设备裁切公差分开

## v3.3 GitHub 印前校验增强
- 对折帖检查：页数/签帖容量、补白、LR/RL阅读方向、纸纹与折线、双面翻转、fold spine位置。
- 对嵌套签帖检查 `pushout <= fore_trim`，否则阻断并要求增加裁量、减少嵌套张数或换更薄纸。
- 对侧缝结构：不计算嵌套push-out，并提示侧缝不具备真正平摊能力。


## v3.5 结构预检
- Springback：检查书背弹性组件曲率、回弹、纸板匹配和书帽对称。
- Sewn Board：检查 guard/flange 是否参与锁线、纸板粘接是否偏斜以及开合时连接件受力。

## v3.7 圆背结构预检
- 检查纸纹是否与书背平行；来源明确要求所有纸材按此方向使用。
- 检查起脊定位是否与所选结构的板厚/来源公式一致；若同时命中45°与90°变体，必须返回冲突并要求结构上下文。
- 检查扒圆后天头/地脚平整、左右圆弧与书肩对称、寒冷纱/书背衬料端部余量、布带槽位置。
- 对非常规圆背复刻，必须记录 `a=书背弧长/宽度、b=书芯高度、c=起脊定位线到书口宽度`，并在裁板前复测。

## v3.8 外露针路预检
增加：孔位分段总长、版心安全、封板/书帖孔位同轴、交叉/不交叉拓扑是否匹配、孔边撕裂、线张力、封板孔磨损、再利用纸袋材料折痕/起翘检查。
### v3.9 手缝孔位预检
- 检查书帖左右端余量是否对称、孔轴是否一致、封板与书帖是否共用同一孔位基准。
- 若标记未确认或左右余量不一致，硬停止打孔。

### v3.10 生产前数量与纸纹复核
- 进入折帖/缝制前先核对页张/书帖分组，不能靠纸堆厚度目测替代计数。
- 纸纹不确定时先做双方向弯曲比较与折样确认，再锁定折口/书背方向。
### v3.12 工业装订工单字段完整性
按 CIP4 Binding ICS 检查对应流程是否具备可表达字段：书芯/介质、CaseMaking、CasingIn、CoverApplication、Folding、SpinePreparation、Stitching/ThreadSewing、Trimming。缺字段先提示数据不完整，不用猜值补齐。
### v3.15 四书蒸馏：PDF装订预检
- 拼版拓宽不得改变原页面内容位置；精装/胶装封面展开尺寸必须由成品宽、书脊及明确的hinge/flap输入计算。
- PDF字体转曲流程必须执行“转曲前检查字体→处理→转曲后再次确认”，但具体Acrobat菜单不作为跨版本硬规则。
