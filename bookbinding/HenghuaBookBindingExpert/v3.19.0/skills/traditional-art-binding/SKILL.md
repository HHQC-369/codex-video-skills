# 传统东方与艺术装帧

## 专属职责
- 只负责：**传统东方与艺术装帧**。
- 跨领域项交给 Orchestrator/对应子 Skill，不在本 Skill 内复制其它岗位逻辑。
- 共用事实边界见 `../_shared/CORE_POLICY.md`。

## 触发条件
- 龙鳞装怎么做白样
- 中式六孔线装

## 必要输入
- 传统结构名称
- 页片/画面
- 展示/保存目标
- 数量

## 专业执行SOP
1. 按canonical传统结构归类
2. 区分卷轴/经折/龙鳞/线装
3. 保留来源变体
4. 先白样再生产

- “锁线装订”不能因包含线装二字误归传统线装
- 艺术结构不得用普通量产参数覆盖

## v3.4 视频增强：龙鳞装
- 复刻视频样本时可调用 `video-dragon-demo-*` 尺寸，但必须注明“样本专用”，不得作为通用龙鳞尺寸。
- 标准执行链升级为：原作展开关系→数字修复→参考线分幅→逐片净裁→背衬/胶粘试样→长底纸基准→单向逐片叠贴→累计漂移检查。
- 长卷装配每片都要校基准，不允许等到最后才检查错位。
- 视频中压敏胶条和背衬的品牌/规格不清楚，收藏/长期展示必须重新做老化与可逆性评估。
- 专属流程：`../../knowledge/video_workflows.json#VW-dragon-scale-reproduction`。

## v3.6 All Sources：中式线装纹样引擎与风琴视频
- 必须读取 `../../knowledge/chinese_stab_patterns.json`：**“六目/八目”是纹样名称，不能按名称自动等同于6/8个物理孔**。
- 六目式视频明确为4个主孔；麻叶式样本为4主孔+5辅助孔；龟甲式样本为4主孔+8辅助孔，并把三个视频保留为针路variant。
- RAR中“中式线装-树形式.mp4”与“波浪式”大小/CRC完全一致，只保留一份证据；“锁线胶装步骤.mp4”内部实际为树形纹，不得路由到胶装。
- 风琴视频新增逐段累计漂移、峰谷一致、灰板/封面方正与完全展开连续画面QC。
