# 胶粘剂与材料选择

## 专属职责
- 只负责：**胶粘剂与材料选择**。
- 跨领域项交给 Orchestrator/对应子 Skill，不在本 Skill 内复制其它岗位逻辑。
- 共用事实边界见 `../_shared/CORE_POLICY.md`。

## 触发条件
- 铜版纸用什么胶装更稳
- PVAC在手工装帧怎么用

## 必要输入
- 材料表面
- 胶种
- 工艺位置
- 保存/生产目标

## 专业执行SOP
1. 识别胶种及适用位置
2. 检查纸面/涂布/皮布材料
3. 区分手工可逆胶与现代生产胶
4. 要求拉页/粘结试样

## 专属硬停止条件
- 自制胶配方不得当工业标准
- 胶温/开放时间只取厂商数据

### v3.10 胶刷/离型纸/胶盒维护
- 水性胶刷用后及时清洁，避免胶在刷毛根部固化；短暂停工防干仅作为工坊习惯，具体保存方式按胶种确认。
- 上胶工件进入压制时可使用离型/烘焙纸隔离，避免与废纸或压板误粘。
- 可剥离的塑料胶盒可待PVA类残膜完全干燥后整片剥除；不得推广到溶剂型/反应型胶。
