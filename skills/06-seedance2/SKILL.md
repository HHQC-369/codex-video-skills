# Seedance 2.0 Skill Router

Upstream: https://github.com/dexhunter/seedance2-skill

## Preferred installation
```bash
npx skills add dexhunter/seedance2-skill
```

## Upstream language files
- `SKILL.md` — English
- `zh/SKILL.md` — 中文

## Use this when
- Writing or refining Seedance 2.0 prompts
- Converting a creative brief into shot/camera/action/audio directions
- Designing ad, drama, MV or educational video prompts

## Boundary
This skill writes/directs prompts; actual video generation still depends on the video-generation service.
