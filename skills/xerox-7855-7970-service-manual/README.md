# 施乐7855，7970维修手册 Skill

这是从你提供的 1 份大型维修手册、3 份现场文档和 8 个操作视频中蒸馏出来的可复用维修 Skill。

## 推荐调用方式

直接说：

> 调用“施乐7855，7970维修手册”，查询 392-314，机器是 7855。

或：

> 调用“施乐7855，7970维修手册”，按视频流程指导我拆五代机定影器。

## 文件结构

- `SKILL.md`：路由、规则、回答模板。
- `references/`：维修知识分册。
- `data/common_codes.json`：常用故障/NVM 快查。
- `data/fault_index.csv`：从 7556 手册状态码章节自动提取的 768 个代码索引（用于检索，不代表都适用于 7855/7970）。
- `scripts/lookup.py`：本地快速查代码/关键词。
- `references/images/`：视频关键帧联系表，方便后期复核操作画面。

## 最重要的适用性说明

当前官方 PDF 实际是 `WorkCentre 7556 Family Service Documentation`，并不是 7970 官方手册。所以本 Skill 会把 7556 官方参数、7855 视频证据、现场经验参数分层，不会把它们混成“7970 官方数据”。

## GitHub 安装说明

本目录是可直接被 Agent/Codex 识别的 GitHub 安装版。核心知识已经自包含进 `SKILL.md`；`data/common_codes.json` 提供常用故障/NVM 快查，`source_manifest.json` 记录证据来源与适用性。

调用示例：

`调用施乐7855，7970维修手册，查询 392-314，机器是 7855。`

注意：7970 当前没有明确的官方维修手册来源，精确 NVM/拆机参数必须标注未验证。
