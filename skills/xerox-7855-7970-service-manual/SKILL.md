# 施乐7855，7970维修手册

本 Skill 的核心目标不是“给一个代码就清零”，而是按照**机型确认 → 故障事实 → 诊断 → 维修 → 必要时复位 → 验收**的顺序处理。

## 证据分级

- **A 级：官方手册来源**：`WorkCentre 7556 Family Service Documentation`。适用于该手册明确覆盖的 7525/7530/7535/7545/7556 系列。
- **B 级：现场操作视频**：用户提供的 7835/7855、四代/五代机视频。可用于操作路径、部件位置、界面流程和拆装顺序。
- **C 级：现场经验文档**：`7855芯片破解过程.doc`、`输稿台边距调整.doc`、`系统错误.doc`。这些是现场经验参数，不等同于官方手册；使用前必须核对机型、固件、当前值，并保留回退值。
- **未验证：7970 专属参数**：当前资料包没有一份明确标注为 WorkCentre 7970 的官方维修手册。对 7970 的精确 NVM、线束、拆装差异不得猜测。

来源与适用性见本文件下方“GitHub 内置维修知识摘要”。

## 维修回答总流程

遇到任何故障时，按以下顺序输出：

1. **确认机型与现象**：型号、故障码、发生时机、是否偶发、打印/复印/扫描哪一项失败、最近更换过什么。
2. **先取证再清零**：优先读取 dC122 最近 40 个故障、dC120 故障计数、HFSI/寿命信息；必要时记录当前 NVM。
3. **按子系统定位**：定影、鼓/显影、转印、纸路、DADF/扫描、控制器、网络扫描、驱动/纸张设置。
4. **执行物理检查**：连接器、异物、磨损、卡滞、传感器、纸张规格、驱动电机等。
5. **使用 dC330/dC140 等做验证**，不要先换板。
6. **只有在原因已处理后**才执行 NVM 清零、HFSI 初始化、dC301 等恢复动作。
7. **复机验收**：打印、复印、DADF、双面、扫描、纸盒、颜色、配置页/故障历史。

官方 7556 手册的服务策略明确要求：先处理 HFSI 高频维护项；基础打印问题先于附件问题；图像质量问题放在其他故障处理之后。详见 [标准维修工作流](references/01_标准维修工作流.md)。

## 高风险动作强制规则

### dC131 写 NVM

- 先 **Read**，记录原值，再 **Write**。
- 任何跨机型、跨固件参数不得直接套用。
- 用户只给“代码”但没给机型时，先说明适用性，再给操作。
- 若来源冲突，优先采用**该机型官方手册**；现场文档作为补充，不静默合并。

### dC301 NVM Initialization

这是恢复性/破坏性动作，不作为普通故障的第一步。执行前应尽可能保存机器设置、客户设置、服务日志中的 NVM 改动，官方手册还建议尽可能使用 dC361 保存 Critical NVM。执行后可能需要重新配置和校准。

### 定影器

必须先停作业、关机、断电，并让定影器冷却。定影组件存在烫伤风险。

### 转印带/鼓

避免直接触摸感光鼓和转印带表面；清洁转印带刮板时不要粗暴摩擦刃口。

## 快速回答模板

当用户提供故障码时，输出以下结构：

**故障含义** → **适用机型/证据等级** → **先做什么** → **诊断步骤** → **可能部件** → **是否需要清零/初始化** → **修完如何验收**。

当用户问拆机/维护时，输出：

**准备与安全** → **拆卸顺序** → **关键卡扣/旋钮/螺丝** → **不可触碰部位** → **装回检查** → **是否需要 HFSI/校准**。

# GitHub 内置维修知识摘要

此部分把原始蒸馏包中最常用的维修知识直接内置到 SKILL.md，保证只读取本文件也可以完成大多数现场判断。

## 诊断模式与 NVM

### UI Diagnostic / CSE Mode
对 7556 官方手册所覆盖机型，标准进入逻辑为：按住数字 0 约 5 秒，在保持 0 的同时按 Start/启动，出现 Service Diagnostics Login 后输入 6789。不同代机型/固件界面可能有差异，操作前先确认机型。

### dC122 / dC120 / dC135
- dC122：最近故障历史，优先看最近 40 个故障及发生时间。
- dC120：故障计数，用于识别高频重复故障。
- dC135：HFSI/寿命信息。先做高频维护项，再处理剩余故障。

### dC131 NVM Read/Write
进入 Adjustments → dC131 NVM Read/Write。输入 Chain/Link 后先 Read，记录原值，再输入新值并 Write。跨机型、跨固件参数不得直接套用。

### dC301 NVM Initialization
属于恢复性/破坏性动作，不作为普通故障第一步。执行前尽量保存 Machine Settings、客户 Tools 设置、服务日志中的 NVM 改动，并在条件允许时保存 Critical NVM。现场文档中的 Copier → Copy Controller / Scanner / Print Engine → NVM Data All → Initialize 属于 C 级现场经验，执行后可能需要纸盒/定位重新校准。

## 常见故障码快查

### 392-314 — ATC Fault [C]
7556 官方 RAP 指向 C 色 ATC 平均值/振幅失败。重点检查 ATC Sensor C、ATC PWB、线束、C 色供粉/显影驱动、供粉路径、Developer 堵粉等。根因处理后才清故障计数：752-348 = ATC Fail [C]，752-352 = ATC Fail Continuous Count [C]。现场文档还给出 Y：752-346/752-350，M：752-347/752-351；官方手册还给出 K：752-349/752-353。实际报 392-314 时优先处理 C 色链路，不建议无差别清所有颜色。

### 342-319 — Drum Y/M/C Motor Fail
先断电检查鼓/显影机械负载，再用 dC330 做驱动测试。若空载不转，检查 +24V/+5V、线束/接插件，再判断 Drive Motor、MD PWB、MCU PWB；若空载可转、装回后不转，重点查鼓/显影卡滞。

### 342-323 — Drum K Motor Fail
与 342-319 类似，但对象为 K 鼓/显影驱动。7556 手册给出 dC330 091-033 作为 K 驱动测试点。

### 310-375 — Heat Belt STS Center Warm Up Time Fault
规定时间内未达到指定温度。先查 dC122 是否同时存在 310-361 IH Driver Input Low Voltage，再检查定影器与主机 Drawer Connector、线路、Fuser Assembly、MCU PWB。不要用清码代替温升故障维修。

### 374-101 — Tray 4 Misfeed
现场文档写作 374.101。含义为 Tray 4 开始进纸后 Feed Out Sensor 未按时 ON。检查 Feed/Lift Up Motor、Takeaway Motor、Feed Out Sensor/执行器、Feed/Retard/Nudger Roll、Takeaway/Pinch Roll、齿轮、纸张规格、线束及 Tray Module PWB。

## 现场 NVM 参数（C 级，谨慎使用）

- 740-062：现场文档记录值 127；还原时记录为 1。7556 官方手册未能交叉验证此项，必须先 Read 保存原值。
- 715-510 / 715-511 / 711-140 / 711-144 / 715-513 / 715-512：来自 78 系现场边距文档。
- 特别注意：7556 官方手册中 711-140 定义为 DADF Lead Registration Adjustment (Side 1)，与现场文档的简写并不完全一致，因此跨代不可直接按同一含义解释。
- 616-014：7556 官方资料中与 SBC NVM 更换后的 Install Wizard 模式相关，值 2 为运行安装向导，值 4 为跳过安装向导进入 install complete；不是普通故障通用清零码。

## 定影系统

### 整件取出
7556 REP 10.1 的核心顺序：确认无作业 → 关机断电 → 等待冷却 → 打开左侧盖 → 松开两个 Knob Screws → 取出 Fuser → 反向装回。更换后该手册覆盖机型需要按规定处理 HFSI 954-850。

### 四代/五代现场视频
定影器取出后可在断电和冷却条件下从端部齿轮手动转动，观察压力辊/热带组件是否平顺，有无卡滞、伤痕、粘附物。五代机深度拆卸视频显示的总体顺序为：外罩/导纸件 → 侧板与端部齿轮/轴端固定 → 逐步释放两端受力结构 → 分离热带/加热组件与压力辊区域 → 拆出压力辊及内部长轴。若需要“每一颗螺丝”的精确位置，应结合当前定影器清晰照片逐点确认，不根据视频盲猜规格。

## 转印带与清洁

纸粉夹在 Intermediate Transfer Belt 与 Cleaner Blade 之间可能形成彩色线条。检查并清理刮板尖端异物/纸粉。不要直接触摸转印带表面，也不要用力来回摩擦 Cleaner Blade 刃口；必要时用软刷或干棉签轻扫，避免破坏刃口保护涂层。

## 扫描稿台、DADF 与边距

玻璃稿台清洁需覆盖主玻璃、窄条扫描玻璃、White Reference Strip 等关键光学区域。DADF 边距调整每次只改单一方向、小步修改：先做基准测试页 → 记录当前 NVM → 单项微调 → 重新测试 → 建立“数值—实测偏移”的本机记录 → 正反面分别验证。

## 纸张、纸盒与打印驱动

7835/7855 现场视频的核心原则是：机器纸盒设置与电脑端 Xerox Global Print Driver PS 的纸张尺寸、纸张来源、纸张类型必须一致。厚卡纸不能机器端定义为厚纸、驱动端仍用普通纸，否则可能等待介质、错选纸盒或使用不匹配的定影参数。

## 颜色与图像质量

Xerox Global Print Driver PS 的图像选项中可调亮度、对比度、饱和度，以及青/红、品红/绿、黄/蓝三组色轴。只有单台电脑或单个应用偏色时才优先从驱动微调；如果复印、测试图和所有打印都偏色，应优先检查玻璃/白参考、Automatic Gradation Adjustment、IIT Calibration/dC945、ATC/显影、LPH/鼓/转印等机器端链路。

## 网络扫描 / SMB

7855 现场视频显示 CentreWare Internet Services 的文件存储库配置使用 SMB，示例端口为 445，需要填写服务器 IP/主机、共享名称/路径、登录用户和密码。Windows 端视频还演示了 SMB 1.0/CIFS 兼容功能；但 SMB1 属于老旧协议，实际部署应先确认设备是否支持更高 SMB 版本，只在确有兼容需求时启用 SMB1，并限制在可信局域网。

扫描失败依次检查：同网段/连通性 → 目标 IP → 共享文件夹 → 共享权限与 NTFS 权限 → 用户名/密码 → 445 端口/防火墙 → SMB 版本 → 共享名与子目录路径是否混淆。

## 复机验收

维修后至少验证：各实际纸盒打印、手送纸、单双面、稿台复印、DADF 单双面、网络扫描、黑白文字、彩色测试图、大面积实地色；再读 dC122 确认原故障没有重新出现。最后必须使用客户最初报错的文件、纸张、纸盒和操作方式完整复现一次。
