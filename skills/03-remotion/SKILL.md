# Remotion Agent Skills Router

Upstream: https://github.com/remotion-dev/skills

## Preferred installation
```bash
npx skills add remotion-dev/skills
```

## Start with
`remotion-best-practices` when the correct sub-skill is not obvious.

## Typical subdomains
- Project/composition creation
- React markup and animation
- Studio preview
- Render
- Captions/subtitles
- Maps/geographic animation
- Multimedia handling
- Upgrade guidance

## Boundary
This is the six-pack integration entry; the complete current Remotion skill collection is upstream.
